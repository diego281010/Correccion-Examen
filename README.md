# Sistema de Entregas con Drones Autónomos

## Descripción

Este proyecto fue desarrollado en Java aplicando los principios de Programación Orientada a Objetos solicitados en la prueba práctica. El sistema simula una empresa de logística inteligente que utiliza drones autónomos para realizar entregas, permitiendo calcular costos de envío según el tipo de dron utilizado.

---

## Características implementadas

- Clase abstracta `Dron`
- Herencia entre clases hijas:
    - `DronLiviano`
    - `DronCarga`
    - `DronEmergencia`
- Encapsulamiento de atributos
- Métodos abstractos y sobrescritos
- Validaciones en setters
- Uso de `Scanner` para ingreso de datos
- Cálculo de costos de entrega
- Uso de constructores con valores quemados
- Modificación de atributos usando setters

---

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)

---

## Funcionalidades del sistema

El programa permite:

1. Ingresar datos del dron por teclado
2. Validar información ingresada
3. Seleccionar el tipo de dron
4. Calcular el costo de entrega
5. Mostrar información completa del dron
6. Modificar datos usando setters y recalcular costos
